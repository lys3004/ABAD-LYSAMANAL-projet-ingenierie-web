# Events Frontend

This project was generated using the Angular CLI (version 20.3.10).

## Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser at `http://localhost:4200/`. The application will automatically reload when you modify source files.

## Code scaffolding

A new component can be generated with the Angular CLI scaffolding tools. For example:

```bash
ng generate component component-name
```

For a complete list of available schematics (such as `components`, `directives`, or `pipes`), run:

```bash
ng generate --help
```

## Building

To build the project, run:

```bash
ng build
```

This compiles the project and places build artifacts in the `dist/` directory. The production build is optimized for performance.

## Running unit tests

To execute unit tests with the [Karma](https://karma-runner.github.io) test runner, use the following command:

```bash
ng test
```
